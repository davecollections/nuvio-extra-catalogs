Nuvio Extra Catalogs

Extra catalog sources for Nuvio collections

A lightweight, Stremio-compatible companion add-on for useful catalog sources that are not currently exposed by Nuvio's standard TMDB catalog experience. The first focus is awards data.

v0.1 proof of concept validated Catalog-only architecture Hosted on GitHub Pages

Install

Add Extra Catalogs to Nuvio

Add the manifest URL to Nuvio's add-on manager. Catalogs from this add-on can then be used directly or selected as sources inside Nuvio Collections.

Manifest URL https://davecollections.github.io/nuvio-extra-catalogs/manifest.json

Designed to work alongside your metadata provider

Extra Catalogs supplies catalogue items and IDs. Full movie or series detail metadata is expected to come from a compatible installed provider, such as Nuvio's official TMDB add-on.
